**Goal:** 驗證器可信度（hook + S6）、驗證終點/觀察層（S7）、不可逆前置閘（S8）、LESSONS 門檻修正——常駐 rules/ 稅不升（只動 kit-evolution 一句）。

## Global Constraints

- **guard 契約（codex 計畫審 R1 修正版）**——四步：
  1. 前置豁免：含 `<<`（heredoc）、以 `echo|printf` 起頭、或含 `pipefail` 子串（涵蓋註解與 `set +o` 變體——文件化 false-negative）→ 放行；
  2. 正規化：`tr '\n' ';'`（newline 即分隔符）→ **引號中和器**（codex R3/R4/R5 收斂版）：有界狀態機（awk，狀態僅 plain/single/double + backslash 跳脫），把每個引號跨段整段換成佔位符 `Q`——替換不刪除保字詞邊界（`&& 'printf' git commit`→`&& Q git commit` 不拼幽靈）、雙引號內 `\"` 正確視為內容不當跨段終點（`grep "foo\" && git commit"`→`grep Q`）、未閉合引號吞到行尾（prefer-FN）；
  3. 單一有序 regex：`(^|[;&([:space:]])` 錨定的測試執行器 → `[^|]\|[^|]` 單管道 → 其後 `(&&|;)[[:space:]]*git (commit|push)`。順序內建（commit 在管道前不攔）、`||` 不觸發、引號前綴不成立錨定；
  4. 明文 unguarded（hook 註解 + S6 記載）＋**定位聲明**：本 guard 是**防呆不是防敵**——目標是誠實工作流的 footgun（quant 三犯非蓄意規避）；蓄意規避（`g'it' commit` 拆字、跨 Bash 調用拆分、`bash -c "…"` 巢狀）屬 v4.9 威脅模型邊界的既有超集（持 Bash 者本可改寫 baseline），不為其建 shell tokenizer——與「Bash 命令解析保護不做」（harness-diagnosis）同一判準。
- **插入點釘死**：canonical hash/state 更新與 call 事件記錄**之後**、通用 N≥3 熔斷 deny **之前**——被攔調用參與 spiral 鏈；pipe-guard 訊息優先於通用熔斷訊息。telemetry 沿用既有 schema：`e:"deny"` + 新欄 `k:"pipe-guard"`，呼叫 log_event 的**實際簽名**（現行三參數，Task 2 Step 1 讀實體確認）。
- 逃生口沿用 `KIT_BREAKER=off`。
- verification-signals 節序 S6/S7/S8 接續 S1-S5，維持「機制一句話 + 編號條目 + 正反例」體例。
- **rules/ 預算不變量（codex R1：二擇一，選 no-growth）**：基線 = 19621B；v4.10 全部 commit 後 `cat .claude/rules/*.md | wc -c` **≤ 19621**——kit-evolution 門檻句的淨增以他處等量縮寫抵銷，數字入 commit message。
- 每 task 結尾 commit；hook 變更 commit 附 hooks-smoke 輸出尾行。

  - v22（引號指令+真 git 參數）：`pytest -q | tail && 'mytool' git commit` → 放行（同 v20 機制）。
  - v23（跳脫引號，codex R5）：`pytest -q | grep "foo\" && git commit"` → 放行（`\"` 是內容不是跨段終點）。

### Task 2: tool-breaker.sh 實作 guard

**Files:** Modify `.claude/hooks/tool-breaker.sh`

- [ ] **Step 1a（telemetry schema 先行）:** log_event 加**選填第 4 參數** `k`（kind）：既有呼叫端零改動（`${4:-}` 預設空、jq 條件性附欄），新增測項驗證舊事件無 `k` 欄、pipe-guard 事件 `e:"deny"` 且 `k:"pipe-guard"`。
- [ ] **Step 1b:** 插入點依 Global Constraints 釘死（state 更新與 call 記錄後、N≥3 deny 前）；實作**必須逐字對應四步契約**（R2-P1a：示意碼與契約不一致時以本段為準，v1-v16 全數必須對這份代碼變綠）：
  ```bash
  # verifier-pipe guard (v4.10): a piped test runner reports the FILTER's
  # exit code; chaining git commit/push onto that green-looking pipe shipped
  # unverified work 3x in one real session (quant 2026-07, fleet receipt
  # 2026-08-02). Stage 1 waivers implement prefer-false-negatives; the
  # single ordered regex implements ordering. Unguarded by design: the
  # shape split across separate Bash calls; quoted shapes that also really
  # commit in the same string.
  PIPE_GUARD_RUNNER='(pytest|vitest|jest|go test|cargo test|npm (test|run test)|bash [^ ]*tests?/[^ ]*\.sh)'
  if [[ "$TOOL_NAME" == "Bash" ]] \
     && ! printf '%s' "$CMD" | grep -q '<<' \
     && ! printf '%s' "$CMD" | grep -qE '^[[:space:]]*(echo|printf)\b' \
     && ! printf '%s' "$CMD" | grep -q 'pipefail'; then
      # quote_neutralize: bounded state machine (plain/single/double +
      # backslash), each quoted span -> placeholder Q. NOT a tokenizer —
      # escaped quotes stay data (codex R5), unterminated quotes swallow
      # the tail (prefer-false-negative).
      CMD_FLAT=$(printf '%s' "$CMD" | tr '\n' ';' | awk '
        BEGIN{FS=""}
        { out=""; st=0
          for(i=1;i<=NF;i++){ c=$i
            if(st==0){
              if(c=="\\"){i++; out=out "C"; continue}
              if(c=="$" && $(i+1)=="\x27"){st=3; i++; out=out "Q"; continue}
              if(c=="\x27"){st=1; out=out "Q"; continue}
              if(c=="\""){st=2; out=out "Q"; continue}
              out=out c; continue }
            if(st==1){ if(c=="\x27") st=0; continue }
            if(st==2){ if(c=="\\"){i++; continue} if(c=="\"") st=0; continue }
            if(st==3){ if(c=="\\"){i++; continue} if(c=="\x27") st=0; continue }
          }
          print out }')
      if printf '%s' "$CMD_FLAT" | grep -qE "(^|[;&([:space:]])${PIPE_GUARD_RUNNER}[^|;&]*[^|]\|[^|].*(&&|;)[[:space:]]*git (commit|push)"; then
          log_event "deny" "$HASH" "$COUNT" "pipe-guard"   # names per Step 1 read-back of actual vars
          jq -n ... deny JSON（照抄既有熔斷 deny 形狀，reason 含 exit code 機制 + 兩條修法：裸跑測試後 commit，或 set -o pipefail）
          exit 0
      fi
  fi
  ```
  變數名（TOOL_NAME/CMD/HASH/COUNT）以 Step 1 讀到的實體為準——**允許改名，不允許改結構**（豁免順序、單一有序 regex、log 在 deny JSON 之前）。
- [ ] **Step 2:** `bash -n` + 跑 hooks-smoke 全綠（**v1-v16 全數**對 Step 1b 的實碼變綠、既有零回歸）。
