# Kit v4.9 減法版 Implementation Plan（rev2，codex R1 findings 全數併入）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans
> to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.
> Spec：`docs/design-history/2026-08-02-kit-v4.9-subtraction-design.md`（rev2）。
> codex R1 verdict=Blocked 的 14 findings 對應處置索引見文末附表。

**Goal:** 常駐 rules/ 稅在行為不退化下實質下降並棘輪鎖定；Stop gate 改「每破檻一次決策（review/defer/skip）」，skip 決策權移交模型（敏感批次除外，敏感亦不可 defer）；順手修復兩個 pre-existing gate 洞（head -50 截斷、migration SQL 盲區）。

**Architecture:** 兩個獨立 workstream。B 先行（gate 重設計，TDD：hooks-smoke 先 RED）；A 隨後（audit → 機械縮寫 → 隔離 A/B eval 降級 → 棘輪）。verify-final-review.sh 重排為「先算後判」佈局：批次計算（changed/business/sensitive/total）先於一切裁決分支，裁決順序 = bypass → fast path → marker → defer → small-allow → turn-scoped → block。

**Tech Stack:** bash hooks（jq、git plumbing）、hooks-smoke.sh（assert_eq/assert_contains + tmp git fixture）、`claude -p`（Haiku 檔）隔離行為評測。

## Global Constraints

- kit repo 內直改 kit-owned 檔（protect-paths 對 kit repo 豁免）；代碼註解英文，文件/commit 中文。
- 敏感地板語意：敏感/protected 批次——model-skip 無效、defer 無效、small-allow 無效（現狀）；僅 review 或 `user-approved` flag 能結清。**執法依據批次內容（hook 端重算），永不信 flag 自述。**
- 不可量測狀態（無 baseline、CERT_TREE 不可解、binary row）一律 fail-closed：small-allow、defer、model-skip 全部無效，落到 block。
- 審計落地（**fail-closed**，codex R2 新 P1）：model-skip（含格式非法與被拒的嘗試）、敏感批次的 user-approved、defer 蓋章/過期，逐筆 JSONL 追加至 `/tmp/claude-kit-skiplog-<session_id>.jsonl`（ts、kind、reason、scope、實測 total/files、tree hash）。**模型發起的路徑（model-skip 生效、defer 蓋章）以 skiplog 追加成功為前提**——`skiplog()` 檢查寫入回傳值，失敗則該決策不生效、flag/defer 消耗、NOTE 註明 audit-unwritable、落回 block。user-approved 不受此限（user 權威 > 審計，log 盡力而為）。/tmp 揮發性照 DEFENSES 誠實條款。
- 威脅模型邊界（明文降格，codex R1-P1d/R2-P1e 裁決線）：持 Bash 的模型可改寫任何 /tmp 狀態檔——偽造 `user-approved`、改寫 defer stamp、乃至直接改寫 baseline line2 認證任意樹（既有超集攻擊）。地板與審計的強度定位=「誠實路徑最省力 + 造假留下可交叉比對的不一致」（stamp/flag 內容 ↔ skiplog ↔ toollog 三方對不上即實錘），非密碼學保證。DEFENSES 誠實條款與月度抽查指引同步此定位。
- marker 既有格式不變；新格式僅三種：defer 檔、`skipped-by=model` bypass 變體、skiplog JSONL。
- rules/ 總量任一 commit 後 ≤ 當時 smoke cap；Task 8 後 cap = min(20480, ceil100(實際×1.05))。
- 每 task 結尾 commit；hooks 行為變更的 commit message 附 hooks-smoke 輸出尾行。
